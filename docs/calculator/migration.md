# 赌场计算器迁移（2026-10-19）

原目录 `D:\自己乱搞的代码\赌场计算器` 的纯数学引擎、完整页面、表单交互、样式、Worker、全部数学测试以及说明文档已迁入本仓库。

| 原文件 | 当前文件 |
| --- | --- |
| engine.js、app.js、worker.js、index.html、styles.css | public/calculator/ 下同名文件 |
| tests/engine.test.mjs | test/calculator.test.js |
| README.md | docs/calculator/original-readme.md |
| VERIFICATION.md | docs/calculator/original-verification.md |

原独立 HTTP 服务、启动脚本和容器配置由本项目统一服务及 Docker Compose 替代。原页面可通过 `/calculator/` 访问，也可在大厅顶部「计算器 → 手动计算」打开。保留原来的模型参数、已见牌、死牌、已知对手、抽水、金额风险提醒、凯利计算、输入偏好、进度取消与 JSON 导出。未新增计算历史数据库。

引擎只做必要扩展：德州允许七位对手；21点可标记分牌手不享受自然黑杰克，并支持牌桌奖金向下取整。手动计算器原有默认规则不变。代码统一用仓库 Prettier 格式。

新增 `live-input.js` 将服务器已经公开给当前玩家的视图转换成计算输入；不访问服务器牌靴、未来牌序或对手暗牌。牌桌下方的 Worker 最多运行15秒，有限牌靴仍保留原120万状态上限；复杂局面明确报错，近似模型必须手动选择。手动面板保留原60秒限时。

新增 `roulette-rules.js` 定义可玩的轮盘号码、合法投注区域与净赔率。服务端采用安全随机数统一开盘，数学引擎独立计算概率，测试逐类核对覆盖数、赔率和期望；也验证多人统一结算、退半及账本守恒。

迁移验证包含原有全部数学测试（含2,598,960种五张牌完整分类）、新旧轮盘赔率一致性、分牌奖金、隐藏信息独立性、七对手支持，以及浏览器实际操作三种手动计算、导出、局内概率、掼蛋整理和轮盘。历史说明文档保留原核验时间，新增规则与限制以本仓库 README 和测试为准。
