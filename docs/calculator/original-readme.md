# 赌场概率实验室 / Odds Lab

Docker 部署名称：`KawaiiCasino`。

中文本地计算器，支持轮盘、21点和德州扑克。无需安装第三方依赖，计算在浏览器 Web Worker 内完成，没有赌场账户连接或实际下注功能。

## 运行

### Docker（推荐）

在项目目录运行：

```powershell
docker compose up -d --build --wait
```

容器名为 `KawaiiCasino`，镜像为 `kawaii-casino:1.0.0`。打开 http://127.0.0.1:5173。
镜像构建会运行数学测试，通过后才生成运行镜像；容器以非root用户运行，并带健康检查与自动重启策略。宿主机端口仅绑定本机，页面计算和浏览器保存输入的行为与本地版本相同。

```powershell
docker compose ps
docker compose logs --tail 50
docker compose stop
docker compose start
```

修改源代码后运行 `docker compose up -d --build --wait` 更新。容器不存储用户场面数据，因此无需数据库或持久化卷。Docker启动后会占用5173端口，避免同时启动本地Node版本。

### 本地 Node.js

需要 Node.js 18 或更新版本。在项目目录运行：

```powershell
npm start
```

打开 http://127.0.0.1:5173。Windows 也可以双击 `启动计算器.cmd`，再打开上述地址。不要直接双击 HTML 文件，浏览器的模块及 Worker 要求 HTTP 服务。

```powershell
npm test
```

测试包含公开21点EV表的数值交叉核对、轮盘所有常见投注、平局与抽水、输入校验、模拟可复现性、全部2,598,960种五张牌的牌型计数，以及随机七张牌与21种五张子集的比较。

## 计算范围

### 轮盘

- 单零37格、双零38格、三零39格，公平且独立。
- 单号、分注、街注、角注、六线、十二数、列注和六种1:1外围投注。
- 美式五数 `0/00/1/2/3`；La Partage 仅适用于欧式1:1投注，0导致净损失一半。
- 显示胜率、赌场优势、单局/多局净EV、固定下注多局标准差和全部全损概率。
- `EV = Σ p_i × 净赔付_i`。标准投注单位EV为单零 `−1/37`、双零 `−2/38`、三零 `−3/39`；美式五数为 `−3/38`，La Partage 为 `−1/74`。
- 多轮结果假设能完成每一轮，不是有限筹码的破产概率。没有预测下个号码或追损算法。

### 21点

- 支持1–8副牌、S17/H17、自然21点3:2或6:5、首两张任意点数加倍、晚投降、已出现牌扣除。
- 默认有限牌靴精确递归，扣除自己手牌、庄家明牌和用户输入的其他已知牌。未知牌按均匀随机排列计算；看不到的底牌包含在剩余牌中。
- 庄家检查自然21点后排除底牌的相应牌值。令剩余未知牌数为N、允许作为底牌的牌数为E，则下一张玩家牌为r的概率为 `c_r × (E − I(r允许为底牌)) / (E × (N−1))`。玩家停牌后，底牌条件概率为 `c_r/E`。
- 要牌EV包括后续每一步最优要牌/停牌。加倍只抽一张，收益与损失都是原始下注的两倍。晚投降是固定净损失0.5倍原始下注。
- 未检查庄家自然21点时，按自然21点导致所有加倍投注损失的规则计算；不支持仅输原始下注的OBO规则。
- **不计算分牌、重分牌、保险、提前投降、Charlie和其他奖励规则。对子只显示候选动作比较，不声称完整最优策略。**
- 这里比较的是已经下注后的选择。当前动作正EV不证明从发牌前下注也是正EV，不自动推荐下一局下注额。
- 可手动选择无限牌靴模型：抽牌独立，A到9各1/13，10值牌4/13；该模型不是当前有限牌靴的精确结果。
- 精确递归超过120万状态会明确报错，浏览器60秒超时也会停止，不会静默切换到近似。剩余牌不足24张或可能耗尽的极端牌靴不支持。

### 德州扑克

- 自己2张手牌；公共牌0、3、4、5张；1–5位对手；可输入已知死牌。
- 每位对手输入具体2张牌，或 `?` 表示所有未冲突组合等概率。**不支持实际行动范围或范围权重；随机对手结果不能直接当作真实对手结果。**
- 7张牌取最优5张，处理A2345、踢脚、公共牌成牌、多人平局，并按 `1/赢家人数` 累积权益。
- 合法场景≤150,000时完整枚举；更大场景按固定随机种子进行蒙特卡洛模拟，每个场景通过局部Fisher–Yates均匀无放回抽牌。
- 展示的95%模拟误差界为Hoeffding界：`ε = sqrt(ln(40)/(2n))`，权益区间 `[max(0,估计−ε), min(1,估计+ε)]`。浮点误差和伪随机生成器不等于理想独立样本；界描述数值抽样误差，**不包括对手模型错误**。
- 底池输入包含对手本次下注、不含你的待跟金额。`最终底池 = 当前可争夺底池 + 待跟注`；`抽水 = min(最终底池×抽水率, 抽水上限)`；上限0表示不抽水。
- `跟注EV = 权益 × 抽水后最终底池 − 待跟注`。只有跟注后直接摊牌、没有未来下注/弃牌、没有边池时，才是完整跟注EV。
- 跟注建议用权益误差界与盈亏线比较，跨越盈亏线则报告无法区分。
- **不提供加注、诈唬、位置、GTO、ICM、隐含赔率或边池策略。** 不能用此摊牌模型推导翻牌/转牌上的通用行动策略。

## 筹码处理

- 所有金额采用同一筹码单位。
- 轮盘、德扑总筹码表示本次下注前可用筹码；21点包含已投入的本局原始下注。
- 校验单局下注/跟注不超过可用筹码；加倍仅在原始下注两倍≤21点总筹码时显示。
- 资金占用提醒线默认5%，只是用户可改的提醒，不是保证盈利的比例。
- 凯利参考数值用完整净收益分布求解 `max Σ p_i ln(1+f×净收益_i)`，负期望时为0。德扑四分之一凯利只是在当前赔率与权益分布可以独立重复时的资金参考，**不是该局加注大小**，也不是严格上限。
- 输入保存在浏览器 localStorage；没有发往远程服务器。导出JSON包含输入、计算模型、结果、随机种子、时间和软件版本。
